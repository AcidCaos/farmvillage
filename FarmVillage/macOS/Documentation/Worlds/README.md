# World engineering index

The current release has sixteen destinations: Home (including the October creation preset), English Countryside, Sunflower Meadows, Lighthouse Cove, Fields of El Dorado, Mediterranean Riviera, Fairytale Fields, Sweet Acres, Oasis Gardens, Emerald Valley, Toy Town, Horseman’s Hollow, Australia, Mystical Groves, Mistletoe Lane and Atlantis. Native macOS and browser/Ubuntu are the active products. iPad/iOS is abandoned. Enchanted Glen and Holiday Lights are retired and must have no active unlock, travel or supported-play offers.

Start with [current world readiness](../../../../WORLD_READINESS.md), [current acceptance](../../../../ACCEPTANCE.md) and [Wave 3](<../../../../Wave 3.md>). Those files define supported scope and remaining work. The documents below retain useful engineering knowledge; their historical results and candidate proposals are not new release acceptance.
